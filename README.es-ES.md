

# adarsha.dev

Mi sitio personal: portafolio, blog y un widget de chat que puede responder preguntas sobre la página que estés visitando.

Construido con Next.js, Tailwind y MDX (contentlayer2). Desplegado en Vercel. El chat se ejecuta con AI SDK.

## Ejecutarlo localmente

Node 22+, pnpm.

```bash
git clone https://github.com/adarshaacharya/adarsha.dev
cd adarsha.dev
pnpm install
cp .env.example .env.local   
pnpm dev
```
